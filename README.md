# WingGame Bot 🤖🃏  
یک ربات تلگرامی بازی ـ کارتی با سبک استراتژیک و فصل‌­های (Season) متغیر

[ صفحهٔ ثبت‌نام / مینی‌اَپ ⬈ ](https://winggame.github.io/wingbot/)  

---

## ✨ ویژگی‌ها
| بخش | توضیح |
|-----|-------|
| کارت‌های خاص | ۳ کلاس اصلی (حمله، دفاع، جادو) + درجه‌های  *Common / Rare / Epic* |
| سیزن | هر فصل کارت‌ و مأموریت‌ تازه + ریست جدول امتیاز |
| نبرد نوبتی | PvE (فعلاً) با دشمنان هوش‌مصنوعی؛ PvP در نقشهٔ راه |
| مینی‌اپ وب | انتخاب پادشاه + نام کاربری در صفحهٔ HTML، برگشت داده به ربات با Web App API |
| اقتصاد بازی | سکه، XP و لوت‌­باکس برای ارتقا یا خرید بسته‌کارت |
| هاست سبک | ربات روی هاست ۱ GB پایتون + فایل‌های استاتیک روی GitHub Pages |
